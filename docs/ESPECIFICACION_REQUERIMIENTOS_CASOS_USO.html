Antes de leer

Este documento está escrito para que la responsable de Dear Angel pueda confirmar si la plataforma refleja la forma real de trabajar del estudio. No es un contrato legal ni un manual técnico. Es la referencia funcional que guiará el desarrollo.

La pregunta principal es: “¿Esto describe correctamente lo que queremos que ocurra en el negocio?” Si una regla no representa la operación real, debe marcarse para cambiarla antes de terminar el sistema.

01 · Visión

Qué resolverá la plataforma

Dear Angel concentrará en un solo lugar el acceso de clientas y personal, la agenda de cada manicurista, el catálogo de trabajos, las cotizaciones personalizadas, los anticipos, las visitas, las recompensas y la administración del estudio.

Clienta

Reservar con claridad

Ver trabajos, cotizar, elegir manicurista, reservar, enviar anticipo y consultar recompensas.

Manicurista

Operar su agenda

Publicar disponibilidad, atender solicitudes, crear citas y registrar asistencia.

Administradora

Controlar el negocio

Gestionar equipo, reglas, contenido, pagos, recompensas, reportes y configuración.

Objetivos del negocio

  1. Reducir el trabajo manual necesario para coordinar citas por mensajes.
  2. Evitar citas encimadas para una misma manicurista.
  3. Mostrar disponibilidad real sin revelar información privada de otras clientas.
  4. Conocer con anticipación el diseño y tiempo aproximado de cada servicio.
  5. Confirmar reservaciones mediante anticipos SPEI revisados por la administradora.
  6. Reconocer las visitas frecuentes con recompensas visibles y auditables.
  7. Dar a la administradora indicadores para tomar decisiones.
  8. Permitir crecimiento del equipo sin rehacer la plataforma.

Alcance incluido

  • Cualquier cantidad de manicuristas, dadas de alta por la administradora.
  • Registro y acceso de clientas mediante teléfono y contraseña.
  • Horarios individuales, citas en línea y citas manuales.
  • Catálogo de diseños, calculadora y cotizaciones revisadas.
  • Anticipo por transferencia, comprobante y confirmación manual.
  • Visitas, recompensas, promociones y notificaciones.
  • Reportes, exportación, auditoría, configuración de marca y respaldos.

Fuera del alcance inicial

  • Sucursales, inventario, tienda en línea, CFDI y cobro del saldo final dentro de la plataforma.
  • Reembolsos automáticos, lista de espera y aplicaciones nativas de App Store o Play Store.
  • Aplicación automática de recompensas al anticipo.
  • Sincronización bidireccional total con cambios hechos directamente en Google Calendar.

05 · Casos de uso

Historias completas de operación

CU-01 · Registrar una clienta

Implementado
Actora: clienta nueva
Resultado: cuenta activa y sesión iniciada
Inicio: selecciona “Crear mi cuenta”
Precondición: el teléfono no pertenece a otra cuenta

Flujo principal

  1. Captura nombre, sexo, teléfono, contraseña y confirmación.
  2. Acepta el aviso de que una menor debe asistir con una persona adulta.
  3. El sistema valida los datos y envía un código por WhatsApp.
  4. La clienta escribe el código correcto dentro de su vigencia.
  5. El sistema activa la cuenta y abre su espacio personal.

Alternativas

Teléfono duplicado: se ofrece iniciar sesión o recuperar acceso. Código vencido: se permite solicitar otro respetando límites.

CU-02 · Recuperar una contraseña

Implementado
Actora: cualquier usuaria
Resultado: contraseña reemplazada y sesiones anteriores cerradas
Canal clienta: WhatsApp
Canal personal: correo
  1. La usuaria escribe su teléfono o correo.
  2. El sistema envía un código al canal correspondiente sin revelar si la cuenta existe.
  3. La usuaria escribe código, nueva contraseña y confirmación.
  4. Puede usar el icono de ojo para verificar temporalmente lo escrito.
  5. El sistema guarda la nueva contraseña cifrada y revoca sesiones anteriores.

CU-03 · Gestionar personal y clientas

Implementado
Actora: administradora
Resultado: perfil creado o actualizado
  1. La administradora busca o selecciona el perfil.
  2. Puede editar datos, iniciar recuperación, pausar, archivar o reactivar.
  3. Para una nueva manicurista, el sistema genera una contraseña temporal si no se captura una.
  4. La manicurista cambia la contraseña en su primer acceso.
  5. Las acciones sensibles se guardan en auditoría.

Restricción: la administradora nunca puede leer la contraseña actual de otra persona.

CU-04 · Configurar disponibilidad

Implementado
Actora: manicurista o administradora
Resultado: horarios publicados actualizados
  1. La usuaria abre Horarios y elige horario global o una manicurista, según permisos.
  2. Agrega o quita periodos diarios; puede dejar un descanso entre periodos.
  3. Puede heredar el horario global, configurar fechas especiales o pausar reservas.
  4. El sistema valida que los periodos no se encimen.
  5. Si una cita queda fuera del nuevo horario, la conserva y muestra una advertencia.

CU-05 · Reservar un horario disponible

Agenda base
Actora: clienta activa
Resultado: horario apartado durante 10 minutos
Precondición: diseño con duración aprobada o duración base
Continuación: anticipo SPEI
  1. Elige manicurista o “Cualquiera” y una fecha dentro del horizonte publicado.
  2. El sistema calcula espacios considerando jornada, descansos, citas y duración.
  3. La clienta selecciona una hora.
  4. La base de datos reserva el intervalo sin permitir que otra solicitud lo tome.
  5. Comienza el plazo para cargar el comprobante del anticipo.

Alternativa: si otra clienta acaba de tomar el horario, se informa y se recarga la disponibilidad.

CU-06 · Crear una cita manual

Implementado
Actora: manicurista o administradora
Resultado: cita confirmada sin anticipo obligatorio
  1. Selecciona clienta registrada por teléfono o captura una invitada.
  2. Indica fecha, hora exacta —por ejemplo 13:43—, duración y notas.
  3. El sistema verifica que cabe en la disponibilidad y no se encime.
  4. La cita se crea confirmada y bloquea el intervalo.

CU-07 · Reprogramar o cancelar

Implementado
Actoras: clienta, manicurista o administradora
Resultado: cita modificada o cancelada
  1. La usuaria abre una cita vigente.
  2. Para reprogramar, elige un horario compatible que no se encime.
  3. Si lo hace la clienta, se exige 24 horas de anticipación y que no haya usado su único cambio.
  4. Si lo hace el personal, no se consume el cambio de la clienta.
  5. Si cancela, se muestra que el anticipo no es reembolsable.

CU-08 · Reservar un diseño del catálogo

Implementado
Actora: clienta
Resultado: diseño asociado a la reserva
  1. Explora trabajos mediante fotografías y filtros.
  2. Abre el detalle con precio, duración y características.
  3. Selecciona “Reservar este diseño”.
  4. El sistema busca disponibilidad usando la duración publicada.
  5. La clienta aparta y continúa al anticipo.

CU-09 · Solicitar cotización personalizada

Implementado
Actora: clienta
Resultado: solicitud pendiente sin bloquear agenda
  1. Configura opciones de la calculadora y observa una estimación.
  2. Adjunta hasta cinco referencias y escribe notas.
  3. Elige una manicurista o “Cualquiera” para revisar.
  4. Envía la solicitud; el sistema no reserva horario todavía.
  5. La clienta consulta el estado desde su cuenta.

CU-10 · Tomar y resolver una cotización

Implementado
Actora: manicurista
Resultado: precio y duración confirmados
  1. Recibe solicitudes dirigidas a ella y solicitudes abiertas a cualquiera.
  2. Si es abierta, la toma; una operación atómica impide que otra la tome simultáneamente.
  3. Revisa configuración, referencias y notas.
  4. Confirma o cambia precio, tiempo y comentarios.
  5. La clienta recibe aviso y solo puede reservar con esa manicurista.

CU-11 · Solicitar ayuda sin diseño

Implementado
Actora: clienta
Resultado: solicitud de contacto asignada
  1. Selecciona “No tengo diseño” y elige manicurista o cualquiera.
  2. Describe brevemente lo que busca o deja referencias opcionales.
  3. Una manicurista toma la solicitud y contacta por WhatsApp.
  4. Tras acordar idea y tiempo, la manicurista crea una cita manual.

CU-12 · Enviar y revisar anticipo

Fase 6
Actoras: clienta y administradora
Resultado: cita confirmada o horario liberado
  1. La clienta ve monto, referencia, cuenta bancaria y políticas antes de pagar.
  2. Acepta expresamente la versión vigente de las políticas.
  3. Realiza SPEI fuera de la plataforma y sube el comprobante dentro de 10 minutos.
  4. La cita queda “Pago por verificar” y conserva el horario.
  5. La administradora revisa y aprueba o rechaza.
  6. Al aprobar se confirma y se emite comprobante digital; al rechazar se libera.

CU-13 · Registrar asistencia y visita

Implementado
Actora: manicurista
Resultado: cita cerrada y visita contabilizada cuando aplica
  1. Abre la cita del día y marca “Atendida” o “No asistió”.
  2. Atendida incrementa una sola vez el contador global de la clienta.
  3. No asistió no incrementa visitas.
  4. El sistema evalúa hitos y desbloquea recompensas nuevas.
  5. Clienta y manicurista reciben aviso si existe un beneficio.

CU-14 · Canjear una recompensa

Implementado
Actora: manicurista
Resultado: cupón marcado como utilizado
  1. La clienta recuerda a la manicurista que tiene un cupón disponible.
  2. La manicurista consulta el perfil y verifica visitas y beneficio.
  3. Elige un solo cupón y lo aplica al cobro físico, no al anticipo.
  4. Relaciona el canje con la cita y lo marca utilizado.
  5. Solo la administradora podrá revertirlo si hubo un error.

CU-15 · Administrar contenido y configuración

Fases 4 y 8
Actora: administradora
Resultado: contenido publicado sin cambiar código
  1. Edita catálogo, calculadora, políticas, recompensas o datos públicos.
  2. Sube imágenes, iconos o logo según el módulo.
  3. Ordena, publica u oculta elementos.
  4. La plataforma valida datos y conserva historial cuando corresponde.
  5. Los cambios publicados aparecen en la experiencia de la clienta.
06 · Reglas del negocio

Condiciones que siempre deben respetarse

ID Regla Razón o efecto
RN-001 Una manicurista no puede tener dos citas cuyos tiempos se traslapen. Protección definitiva en la base de datos.
RN-002 Una cita puede terminar exactamente cuando comienza otra. Permite agenda consecutiva.
RN-003 La clienta reserva en intervalos publicados; el personal puede capturar cualquier minuto. Equilibra facilidad pública y flexibilidad operativa.
RN-004 Pausar o reducir horario nunca borra citas ya creadas. Se advierte para decidir si reprogramar.
RN-005 La clienta reprograma una vez y con 24 horas; el personal no consume ese uso. Política acordada del estudio.
RN-006 Cancelar no genera reembolso automático del anticipo. La plataforma no opera devoluciones.
RN-007 Solo citas atendidas incrementan visitas y lo hacen una vez. Evita premios duplicados o por ausencias.
RN-008 Las visitas son globales por clienta, sin importar quién la atendió. La fidelidad pertenece a Dear Angel.
RN-009 Los cupones no vencen, no se combinan y son de un uso. Se aplican manualmente al pago físico.
RN-010 Los cupones nunca reducen el anticipo. El anticipo protege la reserva.
RN-011 Una cotización personalizada siempre requiere revisión. Precio y duración pueden cambiar por complejidad.
RN-012 Una cotización no bloquea horarios. Solo una reserva con anticipo retiene agenda.
RN-013 La primera manicurista que toma una solicitud abierta se vuelve responsable exclusiva. Evita trabajo duplicado.
RN-014 Tras aprobarse la cotización, solo se reserva con la revisora. Ella validó el tiempo y la ejecución.
RN-015 El horario se aparta 10 minutos durante el pago. Si no se carga comprobante se libera.
RN-016 Solo la administradora aprueba o rechaza comprobantes. Control financiero centralizado.
RN-017 Adultos asisten sin niños ni acompañantes. Política visible antes del anticipo.
RN-018 Menores de 16 años deben asistir con una persona adulta. Se avisa al crear cuenta y reservar.
RN-019 La tolerancia de 10 minutos es informativa. No cancela ni cambia la cita automáticamente.
RN-020 Existe una sola administradora activa. Decisión de estructura del negocio.

RNF-005 Integridad de agenda PostgreSQL impide traslapes aunque dos solicitudes lleguen simultáneamente.
RNF-006 Experiencia responsive Flujos principales utilizables desde 390 px de ancho y escritorio.
RNF-007 Accesibilidad Etiquetas de formulario, navegación por teclado, foco visible, contraste suficiente y texto alternativo.
RNF-008 Claridad Textos en español, errores comprensibles y políticas visibles antes del anticipo.
RNF-009 Rendimiento Consultas paginadas, imágenes optimizadas y respuestas normales objetivo menores a 2 segundos en operación local.
RNF-010 Disponibilidad externa Una falla de WhatsApp, correo o Calendar no corrompe citas ni pagos internos.
RNF-011 Escalabilidad Arquitectura por módulos, cualquier cantidad de manicuristas y servicios externos mediante adaptadores.
RNF-012 Configurabilidad Reglas del negocio editables desde administración sin modificar código.
RNF-013 Auditoría Cambios sensibles guardan actora, fecha, entidad y datos relevantes.
RNF-014 Respaldo Respaldo semanal de base y archivos, con restauración ensayada.
RNF-015 Retención Comprobantes eliminados al cumplir un año; no se eliminan historiales necesarios.
RNF-016 Reproducibilidad La plataforma completa puede levantarse con Docker siguiendo el README.
RNF-017 Observabilidad Health checks para web, API, worker, base de datos, Redis y almacenamiento.
RNF-018 Calidad TypeScript estricto, lint, formato, pruebas proporcionales al riesgo y migraciones versionadas.
Aviso: el aviso de privacidad, términos y políticas finales deberán ser revisados por una persona especialista en legislación mexicana antes de publicar el sistema. Este documento solo describe el comportamiento funcional acordado.

Qué verá la usuaria

Estados de una cita

Estado visible Significado ¿Bloquea horario?
Apartada Horario retenido mientras se carga el comprobante. Sí, durante el plazo
Pago por verificar La clienta ya cargó comprobante y espera decisión. Sí
Confirmada Anticipo aprobado o cita manual creada. Sí
Cancelada La cita fue cancelada. No
Atendida El servicio se completó. No para fechas futuras
No asistió La clienta no llegó. No
Apartado vencido No se cargó comprobante a tiempo. No

Estados de una cotización

Estado Significado Acción disponible
Pendiente Aún no tiene revisora responsable. Una manicurista puede tomarla o la administradora asignarla.
En revisión Una manicurista ya es responsable. Confirmar o cambiar precio y duración.
Aprobada Precio y tiempo definitivos para agenda. La clienta puede reservar con la revisora.
Requiere información Faltan datos o referencias. La clienta complementa la solicitud.
Cancelada No continuará. Solo consulta de historial.

Estados de una recompensa

Estado Presentación Regla
Bloqueada Se muestra el hito pendiente dentro del camino. Aún no alcanza las visitas.
Disponible Cupón visual destacado con aviso. Puede usarse una vez al cobro físico.
Utilizada Permanece visible como parte del historial. No puede usarse otra vez salvo reversión administrativa.
